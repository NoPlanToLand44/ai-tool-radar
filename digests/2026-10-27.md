   https://huggingface.co/papers/2610.33568

   https://huggingface.co/papers/2610.34662
   Signal: 210 upvotes (paper) · score 100.0
   → Proactive video agents inferring implicit user intent (e.g. 'where to click next') rather than waiting for explicit requests. Skip unless you're building browser agents — and even then, proactive intent-guessing is the classic failure mode that makes users distrust agents.

4. [HF] DynaFlow: Learning Free-Form Multi-Agent Orchestration
   https://huggingface.co/papers/2610.34467
   Signal: 150 upvotes (paper) · score 100.0
   → DynaFlow puts free-form workflow synthesis into the main agent's action space, so it decides when to spawn collaborators instead of following a fixed topology. Worth a look — this is the right direction for mirofish-style multi-agent sims, where hardcoded collaboration graphs are the main rigidity.

5. [HF] Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

   Signal: 136 upvotes (paper) · score 100.0
